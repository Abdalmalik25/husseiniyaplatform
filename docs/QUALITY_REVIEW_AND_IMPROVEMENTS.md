# مراجعة الجودة والتحسين الشامل — منصة الحسينية (ALHUSAINIA)

> النطاق: مراجعة عميقة للمتطلبات الوظيفية وغير الوظيفية مع تحسينات قابلة للقياس للمنصة، النظام، تجربة الزائر، الثيمات، الاشتراك، ونموذج التنزيل/التثبيت كتطبيق.
> التاريخ: 2026-08-24

---

## 1) الملخص التنفيذي

المنصة نظام متكامل متعدد المستأجرين (Multi-tenant ERP) مبني على **React 19 + Vite + Tailwind v4 + tRPC + Drizzle/Neon**. المراجعة وجدت نضجاً أعلى من المتوسط في الأمان (JWT + سجل تدقيق + قيود فريدة عالمية) والمرونة (اشتراك لا يغلق النظام أبداً) والإنتاجية. ركّزت التحسينات المنفّذة في هذه الجولة على المستوى العالمي في ثلاثة محاور:

1. **الهوية البصرية**: نظام ثيمات احترافي بست هويات (فاتح/داكن/منتصف الليل/زمردي/وردي/أزرق) يتبدل كاملاً ويخزن تفضيل المستخدم.
2. **دورة الاشتراك**: صفحة «مركز الاشتراك والفوترة» تربط الزبون بحالته الفعلية من الخادم مع سياسات المرونة بوضوح وقنوات دفع/ترقية مباشرة.
3. **تجربة التشغيل**: تحسين صفحة المشاريع (فلاتر ذكية، تعديل مهمة كامل، حذف آمن، مؤشر إنجاز، هياكل تحميل) + ترقية PWA (اختصارات، هوية مستقرة، SW بمؤجل تحديث).

## 2) منهجية المراجعة ونطاقها

- **المصادر المدروسة**: الصفحات (38)، مسارات الخادم tRPC (routers + erpRouter + \_core/subscription)، مخطط DB (drizzle)، ملفات الواجهة العامة (index.html، manifest، sw.js)، النظام البصري (index.css)، الهوية التسويقية (brand.ts).
- **الأدوات**: فحص TypeScript صارم (`tsc --noEmit`)، مراجعات إتاحة الأكواد، تتبع أثر PWA، مراجعة تفاعلات الواجهات.

## 6) اللغة التسويقية والمحتوى الاستشاري

- اللغة الحالية متوافقة ومقنعة: **قيمة أولاً** (قيمة → أدوات → باقات → تواصل)، صياغة عربية سليمة، لا وعود تقنية مبالغ فيها.
- **المحتوى الاستشاري**: بنك أسئلة FAQ، حاسبات تفاعلية (BOQ — مساحة — مالية)، مركز معرفة.
- توصية جارية: تحديث المحتوى الضريبي/القانوني كل ربع وفقاً للوائح المحلية، وتزويد صفحة الاشتراك بنطاق عدّ الإشعارات التجريبية.

## 8) معايير القبول / كيف نتحقق

1. `pnpm check` — صفر أخطاء TypeScript ✅ (تم بنجاح).
2. `pnpm lint` — صفر تحذيرات حرجة (مستحسن).
3. تبديل الثيمات من الهيدر والشريط الجانبي يغيّر كامل السطح فوراً (لا عناصر بصرية قديمة/مكسورة)، ويُحفظ الاختيار بعد الإغلاق.
4. صفحة الاشتراك تعرض حالة حقيقية من الخادم (تجربة/نشط/مهلة) مع العد التنازلي الصحيح.
5. حذف مشروع/مهمة يتطلب تأكيداً مخصصاً (بدون `confirm` المتصفح).
6. تثبيت PWA من صفحة /download يعمل على سطح المكتب والموبايل مع اختصارات manifest.
7. بعد تحديث SW يظهر الإصدار v3 في DevTools → Application → Service Workers.
